# Screenshot fonts

These fonts are used only by the store-art generator. They are not bundled
with the Flutter application.

- `Lora-Medium.ttf`: Lora Medium, available from
  [Google Fonts](https://fonts.google.com/specimen/Lora) and downloaded from
  its [official source repository](https://github.com/cyrealtype/Lora-Cyrillic),
  licensed under the SIL Open Font License 1.1 in `Lora-OFL.txt`.
- `NotoColorEmoji-Regular.ttf`: Noto Color Emoji from the
  [official Noto Emoji repository](https://github.com/googlefonts/noto-emoji),
  licensed under the SIL Open Font License 1.1 in
  `NotoColorEmoji-OFL.txt`.
