# StopCorn website

Static, bilingual website for [StopCorn](https://github.com/Skyost/StopCorn),
built with Nuxt, TypeScript, Bootstrap Vue Next, and pnpm.

## Development

Requirements: Node.js 22.19 or newer and pnpm 11.

```bash
pnpm install
pnpm dev
```

Run every quality check and generate the production site with:

```bash
pnpm check
```

The static output is written to `.output/public`. `nuxt-cname-generator`
generates the `CNAME` file for `stopcorn.skyost.eu`.

## Generated media

From the repository root, generate the application screenshots and social
sharing images, then mirror them into `public/screenshots/` and
`public/social/`, with:

```bash
tool/website/generate.sh
```

Use `tool/website/generate.sh --process-only` to reuse existing raw Flutter
captures. The Open Graph and Twitter images referenced by the SEO metadata are
generated by this pipeline, along with the multi-resolution `favicon.ico`.

## Content and links

- French and English copy lives in `app/locales`.
- Site-wide values, section identifiers, store links, and the future merch URL
  live in `app/constants/site.ts`.
- Store and merch destinations intentionally default to `null`; their buttons
  remain visibly unavailable until an official URL is configured.
  Candidates are Fourthwall, Printify and Spreadshop.
- The app logo is served from the repository-level `assets/branding` directory,
  so the website and mobile app share the same source asset.

The localized, indexable pages are `/fr/` and `/en/`. `/` is a non-indexed
language gateway that preserves URL fragments such as `/#privacy`.
